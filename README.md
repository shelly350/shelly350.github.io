# Shelsy Corado — Personal Website

My personal site: projects, photography, and contact info. Built with React + Vite.

Live at **https://shelly350.github.io**

## Run locally

```sh
npm install
npm run dev
```

Then open http://localhost:5173.

## Update content

Most content (bio, skills, projects, photos, links) lives in `src/data.js`. Photos and the resume go in `public/`.

## Deploy

Pushing to `main` builds and deploys automatically via GitHub Actions (`.github/workflows/deploy.yml`).
